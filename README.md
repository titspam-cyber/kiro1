# Limão Cachorro · Brasil + Bangladesh · Copa 2026

Landing page / proposta de conteúdo, marca, distribuição e captação para o projeto **Limão Cachorro** — uma série documental de humor, cultura e futebol sobre um brasileiro em Dhaka durante a Copa do Mundo 2026.

> *"O país que não joga a Copa, mas torce como se jogasse."*

## Sobre o projeto

Documento confidencial preparado para apresentação a produtoras, marcas e parceiros.

- **Plataformas:** Instagram, TikTok e YouTube Shorts (`@limaocachorro`)
- **Janela:** Copa do Mundo 2026
- **Investimento recomendado:** R$ 48 mil – R$ 55 mil
- **Produção em Dhaka:** 11 jun – 19 jul 2026

## Conteúdo da página

15 seções cobrindo a proposta completa:

1. Diagnóstico estratégico
2. Proposta criativa atualizada
3. Séries e formatos (6 quadros recorrentes)
4. Público e jornada (4 personas)
5. Canais e estratégia de distribuição
6. Ativações criativas e branded content
7. Plano de produção
8. Cronograma macro
9. Frequência de publicação
10. Orçamento (4 cenários)
11. KPIs e ROI
12. Riscos e mitigações
13. Modelo de captação e cotas comerciais
14. Entregáveis comerciais
15. Veredito final

## Stack

Site estático em HTML, CSS e JavaScript vanilla — sem build step.

```
.
├── index.html      # Página única com as 15 seções da proposta
├── styles.css      # Design system + responsivo + print-friendly
└── script.js       # Sticky nav, menu mobile, reveal on scroll
```

## Como rodar localmente

Qualquer servidor estático funciona:

```bash
# Python
python3 -m http.server 8000

# Node
npx serve .
```

Depois é só abrir `http://localhost:8000`.

## Design

Paleta com referências cromáticas a Brasil (verde + amarelo) e Bangladesh (verde + vermelho), em fundo escuro editorial. Tipografia: Bebas Neue para impacto, Playfair Display para citações, Inter para leitura.

A página é totalmente responsiva e tem estilos de impressão dedicados — pode ser exportada como PDF direto do navegador para envio a parceiros.
