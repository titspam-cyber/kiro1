# Imagens do site

Coloque aqui as imagens usadas no `index.html`.

## Arquivos esperados

- `limao-cachorro.jpg` — pintura icônica do projeto (cachorro caramelo mordendo um limão gigante no oceano, com navio à vela ao fundo). Usada como visual principal no hero.

## Recomendações

- **Dimensões:** quadrada ou quase quadrada, mínimo 1200×1200 px.
- **Formato:** JPG (foto/pintura) ou PNG (com transparência).
- **Tamanho:** abaixo de 800 KB para carregamento rápido.
- **Otimização:** comprima em https://squoosh.app/ ou https://tinypng.com/ antes de subir.
